## Purpose

MS Power Platform Notes exists because official documentation is comprehensive but often lacks the practical, hard-won insights that come from real-world usage. This site collects those insights in one place.

## Scope

This site covers the core Microsoft Power Platform products:

- **Power Apps** — Canvas apps, model-driven apps, component libraries
- **Power Automate** — Cloud flows, desktop flows, process automation
- **Copilot Studio** — Custom copilot / chatbot development

## What this site is not

This is not a replacement for [Microsoft Learn](https://learn.microsoft.com/power-platform/). Official docs are linked throughout. This site supplements them with community knowledge.

## Maintainer

This site was started as a personal knowledge base and opened to community contributions. See the [contributing guide](/contributing) to get involved.
