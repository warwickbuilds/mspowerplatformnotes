## Overview

Modern Search in SharePoint Online provides Microsoft Search-powered results from sites, files, people, and other indexed content.

## Core Concepts

- Search quality depends on metadata quality and security trimming
- Crawled and managed properties determine what is queryable and refinable
- Result relevance is affected by user context, signals, and content freshness

## Practitioner Notes

- Invest in metadata and content types early, search experiences improve dramatically
- Standardize naming and page templates to improve result relevance
- Use clear governance for who can create sites and content at scale
- Plan for index latency, especially after large updates or migrations

## Troubleshooting

- Confirm target content is published and not draft-only
- Validate user permissions on content sources
- Check whether required managed properties are queryable and refinable
- Re-test queries in Search and Content Search Web Part contexts
