## What is this site?

MS Power Platform Notes is a community-maintained reference site. It collects practical, real-world notes, links, and patterns that aren't always obvious from official Microsoft documentation.

Start with the [Awesome List](/awesome/power-platform) for curated external resources, or jump into the [Overviews](/overviews/power-platform) for structured summaries of each product.

## Want to contribute?

All contributions are welcome. Read the [contributing guide](/contributing) to get started — it's as simple as forking the repo and opening a pull request.
